One button, one survey, one collector.

Open DevTools Network and click the button. Update data-api-url if you are not running the local demo server.

example.html
<script src="./tinyux.js"
  data-app-id="example"
  data-api-url="/collect"
  data-config='{"debug":true,"surveys":{"maxPerSession":3,"minIntervalMinutes":0}}'></script>

<button data-product="premium"
  data-tinyux-trigger="click"
  data-tinyux-survey-id="post-cta">Upgrade to Premium</button>

<script>
  const ux = window.tinyux.getInstance()
  ux.registerSurvey({
    id: 'post-cta',
    type: 'rating',
    title: 'Quick check',
    question: 'How helpful was the {{data-product}} message?',
    scale: 5,
    cooldownMinutes: 0
  })
</script>

What to look for

  • Upgrade to PremiumShows the rating survey; {{data-product}} becomes "premium" in the question.
  • Ask survey nowOpens the same survey from code with ux.showSurvey('post-cta').
  • Network tabA JSON batch posts to /collect with the interaction, the survey events, and your answer.
